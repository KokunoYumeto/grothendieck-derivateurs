# POLES: my own analysis, written before opening the return (12 Nov 2026, about 14:20)

Notation: `W` a fundamental localizer (Loc 1, 2, 3), so `W ⊃ W∞` (Cisinski 2004, Th. 2.2.11). MV square:
`X = U ∪ V`, `U, V` sieves, `S = U ∩ V`. `N X = N U ∪_{N S} N V` (a simplex of `N X` lies in `U` or `V`
according to its last vertex), so MV squares are homotopy pushouts of spaces. Every span `X_1 ← X_0 → X_2` has
an MV model: the cofibred category `∫` over `(1 ← 0 → 2)`, covered by the sieves over `{0, 1}` and `{0, 2}`.

1. **Lead 1 (cofibre criterion).** With (6′ a): `W` is closed under homotopy cobase change. (6′ b) alone is the
   statement "`e → C(g)` in `W` ⇒ `g ∈ W`" applied to the MV model of `e ← X → Y`; conversely, cofibres of the two
   parallel sides of a homotopy pushout square agree. So (6′ a, b) ⇔ (`g ∈ W ⇔ C(g)` is `W`-aspherical), where
   `C(g) = hocolim(e ← X → Y)` is the unreduced cofibre (`Y_+` for `X = ∅`).
2. **Lead 2.** (6′ b) alone gives `W_Z ⊂ W`: for a homology isomorphism `g` with `X ≠ ∅`, `C = C(g)` is connected
   and acyclic, `C(C → e) = ΣC` is simply connected and acyclic, so contractible, so `C → e ∈ W`, i.e. `e → C ∈ W`,
   so `g ∈ W`. Both steps use only the reverse direction. `W_Z` satisfies (6′ a, b) by excision, and (6 c) by
   the five lemma on Mayer–Vietoris sequences (a direct sum of two maps is bijective iff both are). So
   **`W_Z` is the smallest fundamental localizer with (6′ b)**; `W∞` fails (6′ b), (6 b), (6 C); XVI Th. 5.4 is
   false in its parenthesis; the only fundamental localizer with D_{W_ω} and (6 b) is `Fl(Cat)`.
3. **Lead 4.** `W̃∞ = Fl(Cat)` if Loc (6) = (6 a, b) (Grothendieck's own reading, XVI footnote 13);
   `= W∞` if Loc (6) = (6 a).
4. **Lead 5.** D_{W_ω} ⇔ every `f ∈ W` has `W`-aspherical homotopy fibres ⇔ `W` = maps with `W`-aspherical
   homotopy fibres ⇔ `W` stable under homotopy base change ⇔ (accessible case) the localization is left exact
   (HTT 6.2.1.1). Left exact localizations of `S`: only `S` and the terminal one.
5. **Lead 6.** For `L ⊂ Sp` localizing, `W_L = {g : Σ^∞ C(g) ∈ L}` is a fundamental localizer with (6′ a, b),
   strongly saturated, with Loc (3 bis), (8). `W ↦ L_W = Loc(Σ^∞ C(g), g ∈ W)`; `W ⊂ W_L ⇔ L_W ⊂ L`. Not a
   bijection: `L = Loc(HF_p)` contains no non-zero suspension spectrum (suspension spectra are harmonic,
   Hopkins–Ravenel; `Loc(HF_p)` is dissonant), so `W_{Loc(HF_p)} = W_Z = W_0`. Closed elements on the stable
   side: localizing subcategories generated by suspension spectra. On the unstable side: is `W = W_{L_W}` for
   every (6′ a, b)-localizer? Equivalent to: `Σ^∞_+ : S[W^{-1}] → Sp/L_W` is conservative. Known: `Σ` is
   conservative on pointed objects of `S[W^{-1}]` (`X` aspherical ⇔ `ΣX` aspherical). I could not decide it.
   The class `A` of `W`-aspherical spaces is closed under homotopy colimits indexed by `A`-categories, under
   two-out-of-three in cofibre sequences, under suspension and desuspension, and is a smash ideal.
6. **`W_n` and Loc (7 F): holds.** `W_n` = `P_n`-equivalences. For `f: X → Y` take
   `X → Y ×_{P_n Y} P_n X → Y`. The first map is a `P_n`-equivalence (truncation preserves pullbacks over an
   `n`-truncated base); the second is a base change of a map between `n`-truncated spaces, and base change along
   such a map preserves `P_n`-equivalences (same reason). Model the second map in Cat by a `W∞`-parfait functor;
   then strict base change along it is homotopy base change, so it is in `Fib_{W_n}`. For `n = 0` this is
   Grothendieck's own factorization (XVI ms. 69). The same works for every nullification (a modality).
   This answers XVI ms. 70, 91, 124 ("il faudrait que je teste sur les `W_n`").
7. **`W_Z` (and `W_R`, `R` a field) fails Loc (7 F).** Take `S` with `BS ≃ S¹` and `e → S`. Suppose
   `e → E → S` with `e → E` in `W_Z` (so `E` acyclic) and `p: E → S` in `Fib_{W_Z}`. For any `q: E' → Y'` in
   `Fib_W`: `E'_y → E'/y` and `E'/y → E'/y'` are in `W` (base change of `{y} → Y'/y`, `Y'/y → Y'/y'`); so
   `y ↦ H_q(E'/y)` is a local system and `H_p(Y'; H_q(E'/−)) ⇒ H_{p+q}(E')`. On `S`: `𝒢_q(s) = H_q(E/s)`; `E`
   acyclic and `S ≃ S¹` force `(𝒢_0)_t = Z`, `(𝒢_0)^t = 0`, so `𝒢_0 = Z[t, t^{-1}] = Λ` (a transitive infinite
   permutation module), and `(𝒢_q)_t = 0` for `q ≥ 1`. Let `u: Y' → S` realize a knot complement (trefoil)
   `K → S¹`, a homology isomorphism; `E' = E ×_S Y' → E` is in `W_Z`, so `E'` is acyclic; the local system of
   `E' → Y'` is `u^*𝒢` (base change of `Y'/y → S/u(y)`). Then `E²_{1,0} = H_1(Y'; Λ) = H_1(K̃) =` Alexander module
   `Λ/(t² − t + 1) ≠ 0`, `E²_{0,1} = (𝒢_1)_t = 0`, no differentials reach `E_{1,0}` (`E²_{3,−1} = 0`,
   `E²_{−1,1} = 0`), so `H_1(E') ↠ Λ/(t² − t + 1) ≠ 0`. Contradiction. Hence no factorization: `W_Z` satisfies
   Loc (6 a, b, c, 8, 9) and not Loc (7 F). This answers XVI 7.5 (ms. 105: "Impliquent-ils tout au moins
   Loc (7 F)? Je ne hasarderais aucune conjecture") in the negative. Same for `W_R`, `R` a field
   (`Λ_R/(t² − t + 1) ≠ 0`). To be compared with what the return says.
8. `W_0` satisfies (6′ a), not (6′ b) (circle covered by two arcs), although `W_0 ⊃ W_Z`: containing `W_Z` is
   necessary for (6′ b), not sufficient.
