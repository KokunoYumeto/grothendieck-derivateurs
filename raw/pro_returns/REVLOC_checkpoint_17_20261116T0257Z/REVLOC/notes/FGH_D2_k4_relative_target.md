Now examine the ACTUAL fibration

    Z''=Y<10> -> Z' -> P9.

The base begins in degree7 and the fiber in degree10. Hence
there are no mixed terms of total degree at most16. Every class
of H^j(Z''), 10<=j<=15, is transgressive: an outgoing dr with
r<7 has zero base target, while 7<=r<=j has fiber degree
j-r+1<=9 and thus zero target. The first possible differential
is d_(j+1) to the scalar base line. There are no earlier mixed
incoming differentials to that line in this total range.
Transgression is therefore an unambiguous linear map

    tau:H^j(Z'')->H^(j+1)(P9),  10<=j<=15,

and commutes with the Steenrod operations whose source and
target lie in this range. This is the ordinary cohomology
transgression compatibility from Serre's opened no.7, not a
claim about a later-page operation with unspecified indeterminacy.
