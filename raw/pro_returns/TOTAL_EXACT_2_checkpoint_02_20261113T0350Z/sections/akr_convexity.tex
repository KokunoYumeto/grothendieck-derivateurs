\subsection{A convexity reduction for the exceptional AKR links}

For a concrete AKR object $X$, let $G_X$ be the graph whose vertices
are the arrows $V\to X$ and whose edges are the arrows $b:W\to X$,
joining $bv_1$ to $bv_2$. The functor
$h_V/(bv_1\sim bv_2)$ is $\pi_0G_X$. In the repaired C.1
construction, the opened counting invariant implies that $G_X$ is
simple: distinct $W$-arrows cannot have the same two endpoints.
It also implies that an arrow image induces the corresponding
source graph, since a $W$-arrow whose two endpoints lie in another
arrow image factors through that arrow.

\begin{lemma}[Proved: fixed sets of convex partial isometries]
\label{C:convex-fixed}
Let $S,T$ be finite simple graphs and let $f,g:S\to T$ be induced
graph embeddings. Suppose each connected component of each image
is geodesically convex in $T$, and that both embeddings induce
injections on connected components. Suppose also that the directed
graph with edges $f(x)\to g(x)$ whenever $f(x)\ne g(x)$ has no
directed cycle. Then the induced subgraph on
\[
 F=\{x\in S:f(x)=g(x)\}
\]
is geodesically convex within each connected component of $S$.
In particular its intersection with every component of $S$ is
empty or connected.
\end{lemma}
\begin{proof}
Convex induced graph embeddings preserve distances within each
connected component. Fix $u,v\in F$ in one component of $S$ and
put $a=f(u)=g(u)$, $b=f(v)=g(v)$. Let $I_S(u,v)$ be the finite
set of all vertices lying on a shortest path from $u$ to $v$,
and define $I_T(a,b)$ similarly. Isometry and convexity give
\[
 f(I_S(u,v))=I_T(a,b)=g(I_S(u,v)).
\]
Thus $g^{-1}f$ is a permutation of the finite set $I_S(u,v)$.
If it had a cycle of length greater than one, the corresponding
values under $g$ would give a nontrivial directed cycle of the
relation $f(x)\to g(x)$, with the orientation reversed. This is
excluded. Consequently this permutation is the identity, so
$f(x)=g(x)$ for every $x\in I_S(u,v)$. Every shortest $u$--$v$
path therefore lies in $F$, as required.
\end{proof}

\label{C:convex-obligation}
The repaired quasi-filter construction supplies the no-cycle

\end{remark}

\begin{proposition}[Proved: a limitation of a generic preservation lemma]
\label{C:generic-component-warning}
For arbitrary finite graphs, convex image components, injectivity on
connected components, and bounded point-transition paths do not suffice
to ensure that the repaired beta gluing is injective on connected
components of each old copy. This assertion concerns a generic graph
construction; the displayed arrow configuration is not asserted to
occur in the category generated by C.1.
\end{proposition}
\begin{proof}
Let $S$ have two isolated vertices, let $T$ have vertex set
$\{0,1,2,3\}$ and edges $01,23$, and define induced embeddings
\[
 f:S\to T,\quad f=(0,2),\qquad
 g:S\to T,\quad g=(3,1).
\]
Each image component is a singleton, hence convex, and each map
sends the two components of $S$ to the two distinct components of
$T$. The nontrivial point transitions are the disjoint paths
$0\to3$ and $2\to1$.

Apply the actual-path-size beta formula to these two paths, with
$k=3$, $s=13$, and the common bound $n=3$. Write the two path-coordinate
sets of the target as $L_j,R_j$ for $0\leq j<13$. If
$(u_i,v_i)=(\beta_i^2(0),\beta_i^2(1))$, the image of the two
edges of $T$ in copy $i$ is
\[
 L_{u_i}R_{v_i},\qquad R_{u_i}L_{v_i}.
\]
The thirteen unordered pairs $\{u_i,v_i\}$ are exactly the edges
of the cycle
\[
 0,1,2,3,4,5,6,12,11,10,9,8,7,0.
\]
The resulting graph is therefore its bipartite double cover. Since
the cycle has odd length $13$, this double cover is a connected
$26$-cycle. In particular $L_0=\alpha_0(0)$ and
$R_0=\alpha_0(2)$ have distance $13$ in the new graph, although
$0$ and $2$ lie in different components of $T$.

The file \texttt{finite\_akr\_graph\_gluing.py} independently builds
all thirteen maps, verifies that the target has $26$ vertices and
$26$ edges, checks degree two and connectedness, and prints a
length-$13$ path between these two vertices. The calculation uses
the same repaired beta formula but makes no claim that the two
displayed embeddings are among the arrows produced from the
prescribed C.1 initial category. Thus it invalidates only the generic
preservation lemma with these insufficient hypotheses.
\end{proof}

\paragraph{Additional exact finite checks.}
The program \texttt{finite\_akr\_intersections.py} reconstructs
the selected second-stage attachment and the critical third-stage
attachment specified in the earlier manuscript. It checks that
every arrow induces an injection on $\pi_0G$. For incoming images
of source cardinality at least four it then computes the closure
under all finite intersections and verifies that each intersection
is connected within every ambient $G$-component that it meets.
At the selected second-stage target there are $154$ distinct images
including the identity, $11781$ unordered image pairs, and $307$
distinct intersections with at least two vertices. At the critical
third-stage target the corresponding counts are $892$, $397386$,
and $1189$. In both closures every new nontrivial intersection
already occurs as an intersection of two generating images.
No connectivity or component-injectivity failure occurs.

The separate program \texttt{finite\_akr\_convex.py} checks
geodesic convexity directly. For every vertex of every nontrivial
component of a proper incoming image it compares intrinsic graph
distances with an ambient breadth-first search, also recording
whether an equal-length shortest path can leave the image. It
checks all $153$ proper larger-source images at the selected
second-stage target, using $6732$ source searches, and all $891$
such images at the critical third-stage target, using $52272$
searches. All these image components are geodesically convex.
The small-source image components in these finite stages are
points or edges and so are geodesically convex automatically;
component injectivity was checked separately for all arrows.
The program would reconstruct an explicit shorter or equal-length
path outside an image upon failure. None was found.

These checks concern the two stated finite substages, not complete
later stages and not their infinite union. The output files include
the exact object and arrow counts and the source-size restriction
used in the intersection enumeration. They provide evidence for
a possible convexity induction, not its proof.
