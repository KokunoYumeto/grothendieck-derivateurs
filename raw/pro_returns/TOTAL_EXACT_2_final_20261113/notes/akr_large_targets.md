# Selected large-target AKR counterexample

## Completed theorem and exact scope

`sections/akr_large_targets.tex` contains a proved selected-choice
construction. For every admissible numerical sequence `(a_m)`, there
are choices of sufficiently large repaired targets for which the
first-stage binary H2 generator persists forever. Thus a concrete
quasi-filtered category which is not total is now established.

This is not the universal quantification in C.1. It proves
`for every a-sequence, there exists a choice of targets`, while C.1
asks `for every a-sequence and every admissible choice of targets`.
No conclusion about an arbitrary smaller allowed target is asserted.

## Proof dependencies

1. The exact cell-fiber/attachment kernel theorem
   `C:fixed-path-kernel` identifies every possible old homology death
   with a path between disconnected components of a fixed subgraph.
2. The independent ordered-necklace lemma `C:ordered-necklace` shows
   that every sufficiently long repaired necklace of a pair of
   increasing finite-order injections has an order preserving all
   copy maps. Its strict set-colimit lemma is
   `C:necklace-set-colimit`.
3. The new `C:large-target-convexity` uses a short-path cut. If source
   image components are strongly geodesically convex and component
   maps injective, set D=max old target component diameter and require
   `s>(2n−2)(D+1)`. A shortest path between vertices in one old-copy
   component has length≤D. Its nonfixed vertices' proper visibility
   intervals cover fewer than s indices. Removing an unused overlap
   leaves every path-cell fiber connected, including fixed circles
   turned into paths, and gives a unique coherent lift to a linear
   amalgam. Matching of gluing components makes each old copy strongly
   convex there. Therefore the original shortest path stays in the
   old copy.
4. Maintain two independent auxiliary orders: on actual points and on
   binary graph components. At each pair choose n large enough for both
   path bounds and k large enough for both ordering thresholds, the
   convexity bound, and C.1 arithmetic. Actual point monotonicity gives
   the full source boundedness property directly: every closed
   morphism-chain relation is an increasing partial bijection of a
   finite order. The two auxiliary orders need not be compatible with
   the quotient from points to components.
5. The existing `C:convex-fixed` makes every fixed subgraph convex in
   each source component. The exact kernel theorem then proves all
   stage maps injective on binary H2. The arbitrary-size first stage
   has exactly two nonzero graph cycle summands, from P12 and P21;
   both augment to1. Their difference survives in the union.

## Fully deterministic instance

The proof now includes a choice-free recursive instance. Set
`a0=2` and `a_m=3/2+1/(10·2^(m−1))` for m≥1. The required reciprocal
ratios are5, then `15·2^m+2`, all integers. At each finite stage use
the least odd n≥3 bounding every actual-point and component path.
Choose the least common k satisfying C.1 arithmetic, the diameter
bound, and acyclicity of every point and component precedence graph
generated by the copy order constraints. Such k eventually exists by
the ordered-necklace theorem. Take lexicographically least topological
orders, with canonical finite tags for paths, private/fixed points,
objects, pairs, and arrows. Add the freshly tagged sums and close the
function-tuple hom-sets under composition. Every stage is finite;
the resulting category is countable, and associativity is equality
of ordinary function composition.

The unbounded proof does not rely on finite verification. Earlier
computations remain examples of selected finite behavior and are
not invoked as induction steps.

## Refuted generic route toward the universal claim

Root asked whether connected source/target graphs might allow removal
of the diameter condition. The finite generic search
`akr_connected_convex_search.py` first passed all142 connected simple
unlabelled target graphs with2–6 vertices and all50,132 acyclic
convex-image isomorphism pairs. Of these9,446 cases lay outside the
proved large-target bound and were explicitly checked at k=n, for
every copy. The final rerun also checks for new edges inside an old
vertex image; all counts and outcomes are unchanged. This finite
evidence did not establish the general claim.

An explicit larger connected counterexample was then found and proved
in `C:connected-convex-warning`. Take S a path of L edges, T a cycle
of2L+2 edges, and embed S as its two disjoint length-L arcs via
f(r)=r and g(r)=L+1+r. Both images are strongly convex, component maps
injective, and the point relation has only2-vertex paths. The repaired
target has s vertical length-L columns. Its short end bridges form a
2s-cycle because s is odd, giving an outside path of length s between
the two ends of one column, whose old intrinsic distance is L.
At L46,n3,k11,s45 the old distance46 is shortened to45. These s,n
meet the numerical C.1 first-stage bound with a0=2,a1=8/5.

The standalone exact verifier and certificate are
`akr_connected_convex_counterexample.py/.out/.json`. It verifies all
source hypotheses and the shorter path and exact distance. This is
not an actual C.1 counterexample: no realization of those half-cycle
embeddings as generated arrows has been shown. If T were a protected
first-stage cycle, the nonadjacent-overlap routing theorem would
exclude them. Thus any universal C.1 proof must exploit the generated
arrow structure beyond generic convexity/component-injectivity and
bounded point paths. No further atlas search is needed to decide this
already refuted generic assertion.
