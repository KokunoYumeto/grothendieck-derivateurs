# Ordering repaired beta targets for a selected AKR construction

Status: proved for every sufficiently large k. This is a selected-choice
result and does not assert the universal C.1 persistence statement.

The complete proof is in sections/akr_ordered_necklace.tex:

- C:necklace-set-colimit identifies the actual-path-length repaired target
  with the strict Set coequalizer of its prescribed cyclic necklace.
- C:ordered-necklace proves that for every increasing pair f,g:S->T of
  finite linear orders, all sufficiently large repaired necklaces admit
  an order making every generating copy T->Z increasing.
- C:ordered-necklace-scope gives a terminating rational selection
  procedure and states the exact large-parameter scope.

## Construction behind the proof

Extend the increasing partial bijection f(s)->g(s) to an increasing
piecewise-linear homeomorphism h of the real line. Inside a component of
R minus Fix(h), all positive iterates move monotonically to one endpoint.
Choose k large enough that h^(2k)g(S) lies beyond the finite set f(S) union
g(S) in each such component, in the direction of motion. This condition
continues to hold for every larger k.

An increasing homeomorphism w can then simultaneously satisfy

    w g = f,        w h^(2k) g = h^(2k) g.

The pointwise prescriptions are increasing: in each nonfixed component,
the points fixed by the second prescription lie entirely on one side of
both the domains and images of the first. At fixed points both conditions
agree.

Set

    a_i = h^i,                    0 <= i <= 2k,
    a_i = w h^(4k+1-i),           2k < i <= 4k.

These are actual increasing functions on T, satisfying

    a_i g = a_(i+1) f             (i < 2k),
    a_(2k) g = a_(2k+1) g,
    a_i f = a_(i+1) g             (2k < i < 4k),
    a_(4k) f = a_0 f.

The exact repaired target is the Set colimit of this necklace, so the
functions factor through rho:Z->R. Order Z by rho and break ties inside
fibers. No two points of one generating copy have equal rho-values,
therefore every generating injection is increasing. This argument
handles comparisons between different relation-path components, not only
the monotonicity of beta within each individual component.

## Strict coequalizer verification

For a repaired path of actual length m, the beta image-visibility table
in the TeX proof gives a nonempty cyclic interval for every target point.
The intersection of consecutive copies is exactly the corresponding
f- or g-image. Thus all preimages of one target point are joined by
neighbor relations. Fixed-point fibers are circles and private-point
fibers are singletons. Every prescribed target point is covered. This
shows that the target's equalities are exactly the equivalence relation
generated by the necklace equations; no extra identifications are assumed.

## Numerical compatibility

The lemma permits any additional lower bound on k, including the source's
expansion requirement and a selected graph-convexity bound of the form

    4k+1 > (2n-2)(D+1).

When applied to the component injections H(f),H(g), n must also bound the
actual component-relation path lengths. The physical point-path bound
need not bound these lengths. The ordering assertion itself does not
prove graph convexity or survival of H2; these are separate obligations
being handled in sections/akr_large_targets.tex.

## Finite exploration, not the proof

code/ordered_beta_orderability.py independently constructs the covered
repaired targets and forms the union of every copy's adjacent-order
comparisons. Acyclicity of this directed graph is exactly the required
orderability; a failure would be printed with a directed cycle and the
individual source-copy comparisons witnessing it.

The recorded run in code/ordered_beta_orderability.out checks all 9035
unordered increasing pairs through target size eight, with the least odd
path-length bound n and k=n. No obstruction was found. The program's
failure search would also check the same failing pair at twice and four
times that k. The finite run is exploratory only; the proof above gives
the sufficient large-k statement for every finite pair.
