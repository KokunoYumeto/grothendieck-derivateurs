\subsection{Status of the all-stage homology assertion}
\begin{unresolved}[Part C.1: persistence through every admissible stage]\label{C:all-stage}
For every admissible repaired AKR construction, is
\[
H_2\bigl(\El_{K^*}(K^*(V,-)/(cv_1\sim cv_2));\Z\bigr)\ne0?
\]
The universal assertion is not established in this interrupted record.
The initial repaired first-stage class and its injection through the
entire second stage were checked in the supplied TOTEX proof; they do
not by themselves imply persistence in the union. Proposition~\ref{C:lead7}
does not apply to all future quasi-filters, by
Remark~\ref{C:lead7-limitation}. No separator is claimed.
\end{unresolved}

\begin{proposition}[Proved by finite enumeration: six additional component tests]
\label{C:component-probe}
Starting from the repaired first stage with $s=45$, take the
quasi-filter targets for $(v_1,v_2)$ and $(v_1,v_3)$. At each of
these targets order its $45$ maps from $W$ by their concrete tuples,
and choose the index pairs $(0,1),(0,44),(0,22)$. For each of these
six cases add only the selected second-stage quasi-filter, with
$s=153$. For the fixed pair quotient $H$, every generating map
$\alpha_i$ induces an injection on $H$-values. For each target,
all $11628$ unordered pairs of its $153$ generating maps have
acyclic induced pair graphs on $H$-values; no induced path is
longer than its underlying point-set counterpart. Both maximum
path lengths, measured in vertices, are three. There are no
reversed two-element $H(W)$-actions among the $6732$ incoming
$W$-maps at any of the six new targets.
\end{proposition}
\begin{proof}
The program \texttt{code/topology\_akr\_component\_probe.py}
uses the independently supplied stage implementation, retained
as \texttt{code/topology\_akr\_reference.py}. It builds all
concrete maps of each specified substage and verifies the
neighbor identities and repaired overlap property (11).
For every object, a union--find quotient identifies $gv_1$
with $gv_2$ for every incoming $W$-map; this is exactly $H$.
The induced maps on quotient classes are computed on every
point and checked to be well-defined. Injectivity is tested
by comparing image cardinalities. For every ordered pair
selected for comparison, removing fixed arrows leaves the
partial-injection graph; traversal from all indegree-zero
vertices detects path lengths, and any remaining vertices
would detect directed cycles. Finally a hash set of the
induced maps $H(W)\to H(Z)$ is tested against its reversed
tuples. The output records all six complete checks.
This proposition is deliberately confined to those six
finite targets. It is neither a computation of the full
second stage nor an induction through later stages.
\end{proof}

The remaining prospective induction is stronger than these tests:
one would need to control the homology maps of every future link,
or show that the pair quotient preserves injectivity and adequate
bounds for every relevant morphism chain. A path in the quotient
can join components through different copies of an old object;
the pointwise injectivity of the underlying set maps alone does
not exclude that event. The common-successor or down-set argument
also stops when a sum contains both initial disk targets, because
that down-set already has the nonzero second-homology class.
