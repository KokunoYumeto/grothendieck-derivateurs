## Proofs written

`notes/B_interval_moment_proof.tex` contains a complete finite-dimensional moment-body proof that an alternating simplex image is a closed ball, and a full Reedy proof of the general relative simplex-category/complement comparison. The latter verifies cofibrancy by a locally finite triangulation of a simplex minus a union of faces, using dyadic shells of an explicit piecewise-linear function vanishing precisely on the removed faces. This avoids equating mere NDR data with Quillen cofibrancy.
