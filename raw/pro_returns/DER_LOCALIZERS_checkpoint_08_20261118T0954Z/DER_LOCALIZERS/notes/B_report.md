# Part B: completed findings and audit

Part B is settled in `sections/B.tex`, claims B.1–B.13. The interval proposal is false even with all allowed intervals, a strict test category, and an accessible prescribed localizer. One counterexample is integral homology equivalence on simplicial sets: every acyclic interval is invisible to `NS3`, whereas an explicit finite graph mapping-cylinder inclusion is an integral homology equivalence without the required extension property into `NS3`. The program checks all 36 pairs of elements of `S3`; only 30 occur under precomposition. It also builds the finite graph map explicitly and verifies the identity map on integral `H1`.

**Exact positive characterization on simplicial sets (B.10).** For an accessible non-total fundamental localizer `W`, all allowed intervals generate precisely `C∩W_asph`, where `W_asph` is Cisinski's aspherical core. This core is proper and accessible. Consequently they generate `C∩W` exactly when `W` is proper. A bounded set of actual aspherical simplicial sets, with all their vertices as sections, suffices; the proof uses Cisinski Lemma 6.1.6, Proposition 6.1.1, Proposition 6.1.9 and Theorem 6.1.11. The proof checks that its RLP maps are weak `W`-fibrations before using right properness. It does not assume these maps are already fibrations for the intended localizer. In the total case the interval-generated class is exactly the monomorphisms preserving emptiness.

**One interval versus a set (B.11).** Any set of sectioned intervals can be encoded in their wedge over the selected sections. Each old interval is a pointed retract, and each generator for the wedge is built by attaching the old generators. Thus the weak saturations agree. A single `W`-dependent separating interval therefore suffices whenever the set from B.10 does. This does not claim that one fixed Lawvere interval encodes every prescribed `W`; it explains exactly why that reading of Grothendieck's margin would be too strong.

**A stronger presentation obstruction (B.12).** Every sectioned-interval generator preserves objectwise support. On the strict test category `Delta×[1]`, the representable inclusion `y(([0],0))→y(([0],1))=1` is an ordinary weak equivalence but changes support. In the presentation as diagrams `X1→X0`, it is `(empty→point)→(point→point)`. A natural adjunction from the category of simplices of `X0` identifies the relevant weak equivalences with evaluation-at-0 weak equivalences. Thus the failure persists with the proper accessible ordinary fundamental localizer. The exact properness characterization in B.10 is specifically for simplicial sets. This finite-presentation example has its own program and output. No assertion that `Delta` has finite products is used; strictness follows from Cisinski Corollary 4.1.22, Proposition 4.3.2(g), and Definition 4.3.3.

The same map is itself in `F∩W` for **every** bunch of sectioned intervals. In a lifting square into its empty layer, the generator's source already contains `L1`, forcing `L1` and hence the whole target layer to be empty; the point layer has the unique lift. It has no section, so it is not in `TF` and does not lift against itself. This strengthens the support obstruction to a direct failure of recognition, including a proper-class bunch defined through orthogonals.

**The actual componentwise product case (B.13).** The last sentence of scan020 explicitly says `W_{A/A0}` is defined componentwise through `W_T`. B.12's absolute evaluation-at-0 class must not be substituted for it. The componentwise assertion nevertheless fails even for `W∞`: use `A0=BC2`, `T=Δ`, and the inclusion of the chaotic two-object category on `C2` into its terminal cone. Their nerves are contractible; the first has a free action in every degree and the cone has a fixed apex. The free contractible Kan object `E` maps to the point in `F∩W` for **every** sectioned interval: a map from a generator's source into `E` forces `L` to be free, so the lift is obtained orbit by orbit from the underlying trivial Kan fibration. A lift extending `E→E` over the cone would send the fixed apex to a fixed vertex of `E`, which does not exist. The example works even over an aspherical finite base by adjoining an initial object to `BC2` and putting the point at that new object. Accessibility and all five preliminary hypotheses are checked. The certificate uses categories with 2 objects/4 arrows and 3 objects/7 arrows, and checks 2,625 finite fixed-point-support generator instances.

**Rejected positive proposal.** We considered deriving a positive result for the componentwise ordinary class from representable horn inclusions. On `BC2` those are free projective cells; they do not generate all objectwise trivial monomorphisms when the manuscript prescribes **all** monomorphisms as cofibrations. B.13 explicitly refutes that inference. This correction leaves B.10, the genuine simplicial positive theorem with terminal base, intact.

The exact recognition condition is `F ∩ W ⊆ TF`, equivalently `W=TF∘TC`. Set smallness gives the two weak factorization systems and does not give this recognition. The accessible model existence theorem gives arbitrary generators of trivial cofibrations, not generators of the special sectioned-interval form. B.7 separates identification of the intended localizer from completeness of the Cisinski homotopical structure in slices. The total-localizer empty-object obstruction gives a second counterexample independent of any small-object argument.

For ordinary simplicial weak equivalences, the standard interval with **both** chosen endpoints is complete. A bunch consisting only of `(Delta1,0)` is not complete: `{1}→Delta1` is in `F ∩ W∞` and is not in `TF`. This distinction is explicit in B.5. For integral homology equivalences even the bunch of all acyclic sectioned intervals fails.
